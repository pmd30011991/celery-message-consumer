1. **`mock_channel`** fixture: Returns a `MagicMock` that satisfies the `amqp.channel.Channel` interface enough for `AMQPRetryHandler.__init__` (it will be passed to `kombu.Queue`, `kombu.Exchange`, `kombu.Producer`, `kombu.Consumer`). Since Kombu uses duck typing, a MagicMock is sufficient.

2. **`mock_message`** factory fixture: Returns a factory function `make_message(retry_count=0, acknowledged=False)` that creates a `MagicMock` with:
   - `message.headers` = `{settings.RETRY_HEADER: retry_count}` (or empty dict if 0)
   - `message.ack` = MagicMock()
   - `message.requeue` = MagicMock()
   - `message.acknowledged` = property returning the `acknowledged` parameter (use PropertyMock)
   Note: `acknowledged` must be mutable -- after `ack()` is called in tests, we need to be able to change it. Use a simple attribute that tests can set, or use `side_effect` on `ack` to flip it.

3. **`mock_pool`** fixture: Returns a `MagicMock` with `apply_async` method. The `apply_async` mock should by default capture the `callback` and `error_callback` kwargs so tests can invoke them manually. Use `side_effect` or store on the mock:
   ```python
   def apply_async_side_effect(target, args=(), kwargs=None, callback=None, error_callback=None, **kw):
       # Store for test inspection
       mock_pool._last_call = {
           'target': target, 'args': args, 'callback': callback,
           'error_callback': error_callback,
       }
   mock_pool.apply_async.side_effect = apply_async_side_effect
   ```

4. **`handler`** fixture: Creates an `AMQPRetryHandler` instance with the mock_channel. Must patch `kombu.Queue`, `kombu.Exchange`, `kombu.Producer`, `kombu.Consumer` during construction to avoid real AMQP operations. Use `unittest.mock.patch` on the kombu classes. The handler should have:
   - `func` = a simple MagicMock (the user's message handler)
   - `routing_key` = `'test.routing.key'`
   - `queue` = `'test_queue'`
   - `exchange` = `'default'`
   - `pool` = the mock_pool fixture (set as attribute after construction, since current `__init__` does not accept `pool=` -- Plan 02 will add it; for now set `handler.pool = mock_pool` directly)

Important: Patch `event_consumer.settings.EXCHANGES` to include `{'default': {'type': 'topic'}}` in the fixture so `AMQPRetryHandler.__init__` does not raise `NoExchange`. Also patch `event_consumer.settings.USE_DJANGO` to `False`.

5. **`settings_patch`** fixture (autouse): Patches settings to safe defaults:
   - `MAX_RETRIES` = 3
   - `USE_DJANGO` = False
   - `EXCHANGES` = `{'default': {'type': 'topic'}}`
   - `ARCHIVE_QUEUE_ARGS` = `{}`

<task type="auto">
  <name>Task 2: Write failing unit tests for all Phase 1 requirements</name>
  <files>tests/test_handlers.py</files>
  <action>
Create `tests/test_handlers.py` with unit tests for each requirement. These tests describe the EXPECTED behavior after the fix. They WILL FAIL against the current code (that is correct -- Plan 02 implements the fix).

**POOL-01 -- `test_apply_async_dispatches_callable`:**
Call `handler(body, message)`. Assert that `mock_pool.apply_async` was called with `target=handler.func` (the callable itself, NOT its return value) and `args=(body,)`. Verify `handler.func` was NOT called directly (i.e., `handler.func.call_count == 0` at the point of `apply_async` invocation -- the pool should call it, not `__call__`).

**POOL-02 -- `test_handler_receives_pool_from_get_handlers`:**
Create an `AMQPRetryConsumerStep` instance. Mock `c.pool` and `c.connection.channel()`. Call `step.start(c)`. Assert each handler in `step.handlers` has `handler.pool == c.pool`. This tests the wiring from `get_handlers`. Note: current `get_handlers` does not pass `pool=`, so this test will fail until Plan 02.

**POOL-03 -- `test_listener_returns_immediately`:**
Call `handler(body, message)`. Assert that `handler.func` was NOT called synchronously (check `handler.func.called == False` after `__call__` returns, because the pool should execute it asynchronously). The key assertion: `mock_pool.apply_async` was called, and `handler.func` was NOT invoked directly.

**POOL-05 -- `test_decorator_api_unchanged`:**
Import `message_handler` from `event_consumer`. Use it to decorate a dummy function with `@message_handler('test.key')`. Assert the function is in `REGISTRY`. Assert the decorated function is returned unchanged. Clean up REGISTRY after test.

**ACK-01 -- `test_ack_in_success_callback`:**
Call `handler(body, message)`. Assert `message.ack()` was NOT called inline (not called after `__call__` returns). Then invoke the success callback stored on `mock_pool._last_call['callback']` with a dummy result. Assert `message.ack()` was called exactly once AFTER the callback fires.

**ACK-02 -- `test_permanent_failure_archives` (PermanentFailure path):**
Set `handler.func.side_effect = PermanentFailure("bad data")`. Call `handler(body, message)`. Retrieve the `error_callback` from `mock_pool._last_call`. Invoke it with a simulated exc_info tuple `(PermanentFailure, PermanentFailure("bad data"), None)`. Assert `handler.archive` was called (patch `handler.archive`). Assert `handler.retry` was NOT called.

**ACK-02 -- `test_transient_exception_retries` (transient with retries left):**
Set `handler.func.side_effect = ValueError("transient")`. Message has `retry_count=0`, `MAX_RETRIES=3`. Call `handler(body, message)`. Invoke `error_callback` with `(ValueError, ValueError("transient"), None)`. Assert `handler.retry` was called. Assert `handler.archive` was NOT called.

**ACK-02 -- `test_exhausted_retries_archives` (retries exhausted):**
Message has `retry_count=3`, `MAX_RETRIES=3`. Same as above but assert `handler.archive` was called and `handler.retry` was NOT called.

**ACK-03 -- `test_unacked_requeued_on_error`:**
Invoke `error_callback` where the error handling itself raises (e.g., `handler.archive` raises). After the callback completes, if `message.acknowledged` is still False, assert `message.requeue()` was called. This tests the safety-net in `_on_pool_error`'s finally block.

**ACK-04 -- `test_lambda_capture_correct_message`:**
Dispatch TWO messages rapidly: `handler(body1, message1)` then `handler(body2, message2)`. Collect both success callbacks from the two `apply_async` calls. Invoke callback 1 -- assert it acks `message1` (not `message2`). Invoke callback 2 -- assert it acks `message2`. This verifies default-arg capture prevents late-binding.

**ACK-05 -- `test_retry_count_captured_before_dispatch`:**
Call `handler(body, message)` where message has `retry_count=2`. Retrieve the `error_callback`. Assert that when invoked, the retry_count used in the error callback logic is 2 (captured before dispatch), not whatever the message headers might say later. Specifically: invoke `error_callback` and verify the retry_count parameter passed through is the one captured at dispatch time.

**Important notes for test writing:**
- Each test function should be self-contained.
- Use `pytest.fixture` parameters from conftest.
- For tests that need to inspect callback/error_callback: access `mock_pool._last_call` dict.
- For tests that need `handler.archive` and `handler.retry` to be inspectable: use `unittest.mock.patch.object(handler, 'archive')` and `patch.object(handler, 'retry')`.
- Mark tests that are EXPECTED to fail against current code with a comment `# Expected: FAIL until Plan 02 implements fix` but do NOT use `@pytest.mark.xfail` -- we want them to show as failures.
- The test for POOL-05 (decorator API) should PASS against current code since the decorator is unchanged.
